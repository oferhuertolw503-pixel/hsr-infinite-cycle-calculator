## 当前模拟器数据的限制

`data/characters/*.json` 仍是用于测试引擎的**演示骨架**。其中回能、技能点、
触发条件和光锥效果没有完成逐条官方/游戏内核验，因此：

1. 可以用于学习数据结构和运行模拟器；
2. 不可以据此宣称某支实战队伍能够永动；
3. V2 应按版本、星魂、光锥、遗器、敌人数和敌方机制重新采集数据，并为
   每个数值记录来源。

V1 的完成标准只覆盖截图矩阵复算；“查询角色并寻找新永动机”属于下一阶段。
